finde · quatro jeitos de fechar o programa

A mesma ideia em quatro interfaces. Abra cada uma no celular e veja qual o grupo levaria para a banca.

  1. Conversa

    O Finde pergunta, você responde tocando ou escrevendo. É a versão funcional, com a base de 75 experiências e a votação de verdade.

    abrir a versão funcional

  2. Mesa de cartas

    Um bilhete com cinco carimbos, três cartas na mesa que viram para mostrar o porquê, adesivos com o nome de quem votou.

    abrir o mockup

  3. Roteiro pronto

    Três programas inteiros, cada um com dois ou três tempos numa linha. Dá para trocar um tempo sem desmontar o resto.

    abrir o mockup

  4. Grupo primeiro

    Ninguém responde pelo grupo. Cada amigo marca o que é dele em dez segundos e as opções se ajustam a todos.

    abrir o mockup
Os três mockups rodam sozinhos, com dados de exemplo e amigos fictícios. A versão funcional precisa do servidor do Finde no ar.

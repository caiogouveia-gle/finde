## 1. [P1] A régua de horários não comunica

**Capturas:** `cap/zoom-regua-dia.png`, `cap/zoom-regua-noite.png`, `cap/m390dia-21-resultado-afrouxou.png`, `cap/m390dia-full-07-resultado-inicial.png`

**Onde:** `app.css:419-436` (`.regua`, `.trilho`, `.trilho-festa`, `.trilho-esquenta`, `.regua-horas`), `app.js:23` e `app.js:306-326`.

**Problema:**
- Os trilhos têm 3 px de altura, com linhas de 0,5 px a 3 px umas das outras. Nada liga cada linha à festa dela, e a ordem é a da lista, que hoje nem é cronológica (achado 2).
- A marca do esquenta mede 1,5 px. Por causa do `left` em porcentagem, ela sai com espessuras diferentes de uma linha para a outra: no zoom, uma é fina e a outra grossa.
- Os rótulos de hora usam `justify-content: space-between` e não ficam centrados sob a posição que nomeiam. Os desvios medidos são +8,9 px (17h), +6,9 px (19h), +5,1 px (21h), +4,6 px (23h), +0,5 px (1h) e −7,1 px (3h).
- A janela que a pessoa pediu não aparece. Num resultado com afrouxamento, a régua é justamente o lugar que poderia mostrar a festa das 18h fora de uma janela das 22h às 3h, e não mostra.
- Não há legenda. Ninguém sabe que o tracinho é o esquenta.

**Correção:** tirar a régua do topo e dar a cada entrada uma linha do tempo própria, num eixo comum, embaixo de `.onde`. A linha substitui o motivo "pista cheia às 21h" (achado 7).

```css
.tempo { position: relative; height: 22px; margin-top: var(--e2); }
.tempo::before { content: ''; position: absolute; left: 0; right: 0; top: 7px; height: 1px; background: var(--fio-off); }
.tempo-janela { position: absolute; top: 7px; height: 1px; background: var(--rose); }
.tempo-chega  { position: absolute; top: 7px; height: 1px; background: var(--tinta); }
.tempo-pista  { position: absolute; top: 5px; height: 5px; background: var(--tinta); }
.tempo-hora   { position: absolute; top: 13px; font: 400 11px/1 var(--sans); color: var(--rotulo); transform: translateX(-50%); white-space: nowrap; }
.tempo-hora:first-of-type { transform: none; }
```

- A janela da pessoa é o fio rosé. É um fio, não um texto, então o manual permite.
- Do começo ao esquenta, a festa é um traço fino (`.tempo-chega`). Do esquenta ao fim, é um bloco de 5 px (`.tempo-pista`). A leitura fica "abre fino, enche grosso".
- Embaixo vão só três horas: começo, esquenta e fim (`19h`, `21h`, `1h`), centradas no ponto exato.
- Numa linha só, acima da primeira festa e em 11 px na cor do rótulo, vai a legenda "fio rosé: sua janela · traço grosso: pista cheia".
- No afrouxamento, o trecho do bloco que cai fora da janela passa a vazado (`background: none; border: 1px solid var(--tinta)`). O afrouxamento fica visível sem nenhuma frase.

## 26. Paleta: o grafite não aparece em nenhuma tela, e o rosé só aparece como fio

**Capturas:** todas. Ver `cap/m390dia-31-convite-varias.png` e `cap/d1440dia-31-convite-varias.png`.

**Onde:** `app.css:12` (`--grafite` definido e nunca usado); `app.css:19`.

**Problema:** o manual pede nude 60, bordô 25, rosé 10 e grafite 5. Na prática ficam nude e bordô, com o rosé em fios de 0,5 px, que na noite medem 1,81:1 no fio inativo. Sem foto, sem grafite e sem nenhuma massa de cor, o produto parece um formulário bem composto e não uma marca noturna.

**Correção:** dar ao grafite um lugar fixo, a festa na página do convite, que é a peça que circula no WhatsApp.

```css
.festa-convite { margin: 0 calc(-1 * var(--lateral)); padding: var(--e6) var(--lateral); background: var(--grafite); color: var(--nude); }
.festa-convite .onde { color: var(--rose); }
.festa-convite .sobre { color: #D7BFB4; }
```

É uma faixa de borda a borda, não um cartão. Medir o rosé sobre grafite antes de fechar (estimativa: acima de 5:1). Na noite, subir o fio inativo para `rgba(201,143,138,.5)` (cerca de 2,4:1), para o progresso e os eixos aparecerem.
